# Injection Security Audit — AlUmmahNowAndroid

Audit scope: `core-bridge`, `design`, `player`, `feature-*`, `viewer-mobile`, `viewer-tv`, `studio-mobile`, `admin-mobile`, and all `AndroidManifest.xml` declarations.

## Findings

| Component | Input | Risk | Status | Regression Test |
|---|---|---|---|---|
| `MainActivity.openInBrowser` (`viewer-mobile`), `openInCustomTab` (`studio-mobile`, `admin-mobile`), `openQuranCredit` (`player`) | URL strings opened via `ACTION_VIEW` / `CustomTabsIntent` | Arbitrary URI scheme execution (`intent://`, `file://`, `javascript:`) or cleartext `http://` | Fixed (`SafeInput.isSafeBrowserUrl` requires `https://` or loopback `http://`, no userinfo/control chars) | `core-bridge/.../InjectionAuditTest.kt::safeBrowserUrlRejectsNonHttpSchemesAndUserinfo` |
| `studio-mobile` & `admin-mobile` `MainActivity.handle` | Exported activity `Intent` data & `EXTRA_REVIEW_ID` | Explicit intents from third-party apps bypassed intent-filter `android:path="/callback"` and could supply unvalidated `EXTRA_REVIEW_ID` | Fixed (explicit `data.path == "/callback"` check; `SafeInput.isSafeId` validation on `EXTRA_REVIEW_ID`) | `core-bridge/.../InjectionAuditTest.kt::safeBrowserUrlRejectsNonHttpSchemesAndUserinfo` |
| `HttpReviewService` (`core-bridge`) | Review `id`, `installId` | Interpolated `"/api/review/$id"` before splitting on `/`; `id = "../audit/capture"` or `".."` caused URL path traversal/segment injection | Fixed (uses `List<String>` segments + `SafeInput.requirePathSegment` on every segment) | `core-bridge/.../InjectionAuditTest.kt::httpClientsRejectPathTraversalSegmentsBeforeNetwork` |
| `TemporaryCatalogRepository` & `HttpLiveRepository` (`core-bridge`) | `videoId`, `category`, `streamId` | `category` was interpolated into `addPathSegments(...)`; `id = ".."` popped segments in OkHttp `addPathSegment` | Fixed (`SafeInput.requirePathSegment` + single `addPathSegment(safeCategory)`) | `core-bridge/.../InjectionAuditTest.kt::httpClientsRejectPathTraversalSegmentsBeforeNetwork` |
| `PrivateHttp.noStore` (`core-bridge`) | HTTP 3xx `Location` redirects | Only compared `next.host != url.host` (missed port/scheme change) and did not strip `X-AUN-Native-Proof` on cross-origin redirect | Fixed (compares scheme + host + port and strips both `Authorization` and `X-AUN-Native-Proof`) | `core-bridge/.../InjectionAuditTest.kt::privateHttpStripsAuthAndProofOnCrossPortRedirect` |
| `TemporaryTusUploadEngine` (`core-bridge`) | TUS `endpoint` | Sent `Authorization: Bearer` without verifying `https://` (or loopback `http://`) | Fixed (`SafeInput.isSafeBrowserUrl(endpoint)` guard before sending bearer token) | `core-bridge/.../InjectionAuditTest.kt::safeBrowserUrlRejectsNonHttpSchemesAndUserinfo` |
| `AunLog` (`core-bridge`) | `area`, `message`, `context` values, throwable stack | CR/LF log forging and accidental secret/PII leakage into logcat | Fixed (`SafeInput.sanitizeLogLine` on tag/message/context; `SafeInput.scrubSecrets` on stack traces) | `core-bridge/.../InjectionAuditTest.kt::aunLogSanitizesNewlinesControlCharsAndSecrets` |
| `AppLinkParser`, `ShortLinks`, `SupportLinks`, `ViewerReportUrls` (`core-bridge`) | Deep links, `webHost`, `siteHostOrOrigin`, channel handles | `userInfo` in `https://` deep links, `.`/`..`/`\`/control chars in handles, unvalidated hostname strings interpolated into `https://` URLs | Fixed (rejects `rawUserInfo`, `.`/`..`/`\`/control chars in handles; `SafeInput.isSafeHostname` on host params) | `core-bridge/.../InjectionAuditTest.kt::appLinkAndShortLinksRejectUserinfoAndHostInjection` |
| `PendingExports` (`studio-mobile`) | `userId` and `PickedFile.name` | Blank `userId` resolved `dir("")` to export root (`remove("")` would wipe all accounts); `it.file.name` unchecked before `File(dir, name)` | Fixed (`require(userId.isNotBlank())`, rejects `.`/`..`, checks `SafeInput.isSafeFileName`) | `studio-mobile/.../PendingExportsTest.kt` |
| Manifest exports (`AndroidManifest.xml` across all apps) | Exported activities/services | Unnecessary component exposure | OK (only launcher/deep-link `MainActivity` and `AunPlaybackService` MediaLibraryService are exported; `AdminMessagingService` is `exported="false"`; `allowBackup="false"` everywhere; `admin-mobile` sets `usesCleartextTraffic="false"` and `FLAG_SECURE`) | N/A |
| WebViews / HTML rendering / Local SQL / Process launches | N/A | WebView JS/file access, XSS, SQLi, command injection | OK (no WebViews, no `Html.fromHtml`, no Room/SQLite/raw SQL, no `ProcessBuilder`/`Runtime.exec`; Compose renders all text as plain strings) | N/A |
